# Aesop Learning Lab

A local-first personal learning application that tests whether its instructional choices improve delayed, independent performance. AI may assist development but is not required at runtime.

The [project brief](docs/project-brief.md), [module contracts](docs/module-contracts.md), and [delivery board](docs/delivery-board.md) define the first prototype. This is a new project, separate from Aesop Cognitive Core and Director Orchestrator.

Source concept: https://chatgpt.com/s/t_6accfb5560548191bdc0ba8d133d8b8d

## First prototype

One bounded programming subject with approximately 20 related concepts, reviewed lessons, independent practice, a hint ladder, delayed checks, a transparent review scheduler, one fixed comparison of two teaching approaches, and learner-controlled insights. Python and SQLite are the proposed core; a thin browser UI is the initial client.

The prototype must distinguish unassisted from assisted success, immediate from delayed performance, and familiar from unfamiliar tasks. It must not infer a permanent learning style or require a language model while running.
