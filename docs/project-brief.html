Project brief

Product outcome

Improve each person's learning experience, using Python functions and recursion as the first bounded topic. Adapt the next activity to observed evidence through transparent rules, and let learners adjust the presentation and time available. Keep retrieval, feedback, and delayed checks in place even when easier study feels more comfortable. Test whether the adaptive approach improves delayed and unfamiliar performance over a competent fixed routine. Do not infer a fixed learning style from preferences.

V1 acceptance criteria

  1. A reviewed content pack covers approximately 20 related concepts in Python functions and recursion. It contains prerequisites, versioned lessons, examples, exercises, answer keys, and citations to authoritative teaching material. Content is reviewable before release.
  2. A session presents an activity, records the first answer and any hints, scores only what can be scored reliably, and suggests the next step with an explanation and an override.
  3. The record keeps recognition, recall, explanation, application, and transfer evidence distinct. It never reduces these to an unexplained mastery percentage or a fixed learning-style label.
  4. Delayed checks can be scheduled after one day and one week as configurable pilot defaults. Familiar and unfamiliar assessment items are marked separately.
  5. One comparison assigns matched fresh material to two defined approaches using a recorded seed and a fixed protocol. It records exposure, content version, outside-study annotations, and uncertainty. A good fixed routine is the baseline.
  6. The learner can inspect, export, correct where appropriate, and delete local records. No webcam, microphone, passive behavior tracking, or runtime AI is required.
  7. The application is usable with keyboard navigation and communicates status and errors clearly.
  8. V1 never executes learner-submitted code. It can automatically score bounded choice and trace questions; explanations and open-ended code receive a visible self or human review rubric.

Out of scope for V1

Multiuser accounts, cloud sync, arbitrary-subject grading, automatic scoring of free-form explanations, psychological trait inference, integration with Aesop Cognitive Core, and a claim that personalization has been proven effective before delayed data exists.

Success evidence

Report delayed unassisted performance, unfamiliar-task performance, time to defined standard, hint dependence, sustainable participation, and calibration between confidence and outcomes as separate measures. Treat findings as limited to the tested conditions.
