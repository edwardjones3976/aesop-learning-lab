Prospective descriptive pilot v3

V3 is for new v6 learners only. Existing learners remain pinned to their v1/v4 or v2/v5 content, assignments, and exposure records. V3 uses a new fixed seed (20261019) and the same text-versus-labeled-diagram conditions, self-paced 10-minute study target, first-response rule, and 7–14 day primary window as v2. It freezes the v6 held-out families before enrollment, including the new recursive-case-lamp-toggle-week-v6 family for recursive-case tracing. The other four families retain their authored IDs across content versions where their assessment task is unchanged.

Import DESCRIPTIVE_V3, ExposureV3, assign_condition_v3, and analyze_v3 from aesop_lab.experiment.descriptive_v3. The local application must route v4 to v1, v5 to v2, and v6 to v3; each analyzer rejects another protocol's assignment and exposure records. Persist the first v3 assignment per concept and pass only v3 records with the stable local learner ID to analyze_v3. No v1 or v2 data migration is part of this protocol.

Draft candidate-key matches are provisional, not eligible primary outcomes. Reviewed independent first responses inside days 7–14 can enter the primary count. Late but otherwise independent first responses are described separately with actual elapsed seconds and days. Missing, contaminated, ungraded, early, and exposure-incomparable observations stay distinct. Recorded study time is not proof of equivalent exposure. A local database has one independent learner; its five concept outcomes cannot satisfy the minimum of 20 independent learners per arm. V3 reports insufficient_evidence and no teaching-method winner.
