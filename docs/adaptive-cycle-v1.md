# Five-concept adaptive cycle (development pilot)

Run the local preview with `PYTHONPATH=src python -m aesop_lab.foreman` and use a fresh local database to see content version `v4`. Existing records stay pinned to their referenced pack version. The five v4 lessons offer the same written explanation and retrieval activities in both assigned conditions; the diagram condition adds a labeled diagram. A random local learner ID and the fixed seed determine a stable, balanced assignment across concepts. The ID, assignment, lesson exposure, attempts, and overrides are exportable and deleted by the local delete control.

The learner's first answer and optional confidence are saved before hints. Hints then progress from nudge to targeted to worked solution. Candidate-key matches are development observations, and free-form explanations remain ungraded pending rubric review. The scheduler uses recorded errors, hint use, independent recall and application, then offers one-day and seven-day held-out checks when due. The learner can choose practice instead, with the override recorded separately.

The fixed `text-vs-labeled-diagram` protocol is version `v1` in `aesop_lab.experiment`. Its primary outcome is the first independent, deterministically graded response to a versioned, unseen day-seven application or transfer family. Missing, assisted, early, late, ungraded, and previously encountered families are not counted as incorrect. Assignment and analysis can be replayed with an injected clock. The content pack and keys still need independent instructional review, and lesson duration is self-paced rather than controlled. The comparison therefore reports `insufficient_evidence`; no teaching-method or mastery claim follows from simulated checks.

For a real next-day observation, use the same learner record after at least 24 hours, inspect the due check and its reason, record the first response without hints, and verify its timestamp, family, content version, assistance and grading method in export. Repeat at seven days for a new held-out family. Controlled-clock automated tests validate scheduling and state transitions only; they do not substitute for elapsed real time or human learning data. Before a controlled human comparison, obtain an independent content/key review receipt and define an enforceable, comparable instructional exposure protocol in a new version.
